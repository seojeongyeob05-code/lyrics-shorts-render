## 2026-11-25

**한 일: 처음 켜기 쉽게 (더블클릭 시작 파일, 버전 안내, 휴대폰 주소)**

사용자가 "사이트 들어가 볼 수 있나"고 물어 와서, 직접 켜 볼 때 막힐 만한 곳을 정리했습니다.

- 더블클릭 시작 파일: 윈도우는 `시작하기.bat`, 맥·리눅스는 `start.sh`.
  - Node.js 확인 → 처음이면 필요한 파일 설치 → 서버 실행 → 브라우저 열기를 한 번에 합니다.
- Node.js 버전 안내: 서버는 Node.js 22.13 이상의 내장 SQLite를 씁니다. 윈도우 PC에 흔한 Node 18·20에서는 지금까지 영어 오류로 바로 꺼졌습니다. 이제 무엇을 설치해야 하는지 한국어로 알려 주고 멈춥니다.
  - 고치기 전에는 `npm start`가 Node 18에서 "bad option: --disable-warning"으로 실패했고, 직접 실행해도 알아보기 힘든 오류가 났습니다.
  - 새 시작점 `server/main.js`가 버전을 먼저 확인한 뒤 서버를 불러옵니다. 경고 숨기기도 명령 옵션이 아니라 코드에서 하므로 옛 Node에서도 안내 문구까지 나옵니다.
- 서버 창 안내: 켜지면 같은 와이파이의 휴대폰·다른 PC에서 접속할 주소(예: `http://192.168.0.12:3000`)와 끄는 방법을 보여 줍니다.
- 포트(3000번)를 이미 다른 프로그램이 쓰면 한국어로 알려 줍니다.
  - 버그 수정: Express 5는 포트 오류 때도 "켜짐" 콜백을 부르기 때문에, 오류 직전에 "실행 중"이 잘못 찍혔습니다.
- `npm start`, Docker도 새 시작점(`server/main.js`)을 씁니다. `node server/index.js`도 그대로 됩니다.
- 테스트 2개 추가 (버전 판별, 와이파이 주소 고르기. 전체 86개 통과). 확인한 것:
  - Node 18을 받아서 고치기 전·후를 비교했습니다. 전: 알아보기 힘든 오류. 후: 한국어 안내, 종료 코드 1.
  - `node_modules`가 없는 새 복사본에서 `start.sh`가 설치 → 실행까지 한 번에 되고 API가 응답했습니다.
  - 포트가 겹치면 안내만 나오고 꺼졌습니다.

**확인하지 못한 것**

- `시작하기.bat`은 이 작업 환경(리눅스)에서 실행해 볼 수 없었습니다. CRLF 줄바꿈과 UTF-8(chcp 65001)로 만들었고, 한글이 깨져 보이더라도 동작에는 영향이 없도록 한글은 안내 문구에만 썼습니다.
- Docker 이미지는 이 환경에 Docker가 없어 빌드해 보지 못했습니다 (시작 명령만 바뀜).

- Shift+↑/↓로 볼륨을 5%씩 올리고 내립니다. 그냥 ↑/↓는 목록 스크롤에 쓰도록 비워 두었습니다.

- 단축키 안내(?)에도 새 단축키가 나옵니다 (안내가 단축키 표에서 그려지므로 자동으로 반영).

- 테스트 2개를 추가했습니다: 중복 업로드(다른 이름, 같은 요청 안의 중복, 디스크에 파일이 남지 않는지)와 예전 DB 마이그레이션·해시 채우기 (전체 17개 통과). 어제까지 쓰던 실제 데이터로 서버를 켜서 마이그레이션이 되는지, 브라우저에서 같은 파일을 다시 올리면 건너뛰는지도 확인했습니다.

**참고**

- 같은 곡이라도 비트레이트나 형식이 다른 파일(예: MP3와 FLAC)은 내용이 달라 중복으로 잡히지 않습니다.
- 곡이 아주 많으면 처음 서버를 켤 때 해시 계산에 시간이 걸릴 수 있습니다. 백그라운드에서 돌기 때문에 그동안에도 사용할 수 있습니다.
