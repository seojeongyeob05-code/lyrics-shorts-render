## 2026-11-01

**한 일: 곡 검색 추가, macOS 한글 파일명 버그 수정**

- 라이브러리와 플레이리스트 화면 위에 검색창을 추가했습니다. 제목·아티스트·앨범에서 찾고, 대소문자와 띄어쓰기는 무시합니다.
  - 초성 검색: `ㅂㄴ`으로 "봄날의 노래"를 찾을 수 있습니다.
  - `/` 키로 검색창에 바로 들어가고, `Esc`로 검색어를 지웁니다.
  - 검색 결과에서 곡을 누르거나 "재생"을 누르면 검색 결과만 재생 목록이 됩니다.
  - 검색 중에는 플레이리스트 드래그 정렬을 막습니다 (보이는 순서와 실제 순서가 달라서).
- 버그 수정: macOS에서 올린 한글 파일명은 자모가 분리된(NFD) 형태라 화면에는 정상으로 보여도 검색·정렬이 안 됐습니다. 업로드할 때 파일명과 태그(제목·아티스트·앨범)를 NFC로 합쳐서 저장합니다.
  - 이미 올라가 있는 곡은 DB에 그대로 남지만, 검색 쪽에서도 NFC로 맞춰 비교하므로 검색은 됩니다.
- 테스트: 검색 단위 테스트 5개와 NFD 업로드 테스트 1개를 추가했습니다 (전체 12개 통과). 브라우저에서도 초성 검색, 검색 결과 재생, Esc 초기화를 확인했습니다.
