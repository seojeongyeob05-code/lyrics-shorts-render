# 🎵 My Music — 개인 음악 스트리밍 서버

내가 가진 음원 파일(MP3, FLAC 등)을 서버에 올려 두고 브라우저에서 듣는 웹앱입니다.
집 PC나 개인 서버에서 실행하고, 계정 하나로만 접속합니다.

> 직접 구매했거나 이용 권한이 있는 음원만 올려 주세요. 다른 사람에게 공개하거나
> 공유하면 저작권 문제가 생길 수 있습니다.

## 기능

- **로그인**: 처음 접속할 때 계정 하나를 만들고 이후 가입은 막힙니다. 쓰는 동안에는 로그인 유지 기간(30일)이 자동으로 연장됩니다. 사이드바 아래 아이디를 누르면 비밀번호를 바꿀 수 있고, 바꾸면 다른 곳의 로그인은 끊깁니다. 비밀번호는 scrypt로 해시하고, 로그인 실패가 반복되면 잠시 차단합니다.
- **업로드**: 파일 선택 또는 창에 끌어다 놓기. 폴더째 수백 곡을 올려도 자동으로 나눠 보내고, 너무 큰 파일만 건너뜁니다. 제목, 아티스트, 앨범, 트랙 번호, 커버 이미지를 태그에서 자동으로 읽습니다 (태그가 없으면 파일명을 제목으로 씀). 이미 있는 곡과 내용이 같은 파일은 건너뜁니다.
- **재생**: HTTP Range 스트리밍이라 탐색바로 원하는 위치로 바로 이동할 수 있습니다.
- **플레이어**: 재생/일시정지, 이전/다음, 셔플, 반복(전체/한 곡), 볼륨·음소거, 스페이스바로 재생 토글. 볼륨 슬라이더·스피커 위에서 마우스 휠로 볼륨 조절
- **재생 대기열**: 다음에 재생 / 대기열에 추가, 드래그로 순서 변경, 빼기. 새로고침해도 대기열과 재생 위치가 유지됩니다.
- **미디어 키**: 키보드 미디어 키와 OS 미디어 컨트롤(Windows 볼륨 오버레이, macOS 제어 센터)로 조작, 곡 정보·커버 표시
- **가사**: 싱크 가사(.lrc)는 부르는 줄을 강조하고 따라 스크롤, 줄을 누르면 그 부분부터 재생. 붙여 넣기·.lrc 불러오기·파일 태그에서 자동으로 가져오기. 음원과 같은 이름의 `.lrc`를 함께 올리면(또는 `.lrc`만 올리면 같은 제목의 곡에) 자동으로 연결, EUC-KR 파일도 지원
- **가사 싱크 맞추기**: 일반 가사를 노래에 맞춰 Enter로 한 줄씩 찍어 싱크 가사(.lrc)로 만들기. 0.75×·0.5× 느리게 재생 가능
- **곡 정보 수정**: 제목·아티스트·앨범을 화면에서 고치기 (원본 파일 태그는 그대로)
- **아티스트·앨범별 보기**: 커버 카드로 둘러보고 카드에서 바로 재생, 앨범은 디스크·트랙 순서대로. 곡 목록·플레이어·대기열의 아티스트·앨범 이름을 누르면 그 화면으로 이동
- **여러 곡 선택**: 체크박스·Shift 범위·Ctrl/⌘+클릭·Ctrl/⌘+A로 골라 한 번에 재생, 대기열·플레이리스트에 추가, 삭제
- **최근 추가 · 많이 들은 곡 · 최근 들은 곡**: 곡을 절반 이상 들으면 들은 횟수와 때를 기록하고, 많이 들은 순·최근 들은 순("3시간 전" 등)으로 모아 보기
- **키보드 단축키**: Space 재생, ←/→ 5초 이동, Shift+←/→ 이전·다음 곡, Shift+↑/↓ 볼륨, M·S·R·L·Q, / 검색, ? 안내 (한글 입력 상태에서도 동작)
- **백업·복원**: 곡 정보 수정·가사·들은 횟수·플레이리스트를 JSON 한 파일로 백업. 음원을 다시 올린 뒤 복원하면 파일 내용으로 같은 곡을 찾아 되살림 (음원 파일은 백업에 들어가지 않음). 서버가 하루 한 번(계정을 처음 만들 때도 바로) 자동 백업하고 최근 7일치를 보관하며, 백업 창에서 날짜를 골라 바로 복원
- **검색**: 제목·아티스트·앨범 검색, 초성 검색(`ㅂㄴ` → "봄날의 노래"), `/` 키로 바로 검색
- **플레이리스트**: 만들기, 이름 변경, 삭제, 곡 추가(⋯ 메뉴 또는 사이드바의 플레이리스트 이름 위로 곡 끌어다 놓기), 드래그로 순서 변경. 이미 있는 곡을 넣으려 하면 새 곡만 넣을지 물어봄. `.m3u`/`.m3u8`로 내보내기·가져오기 (다른 플레이어의 목록도 아티스트·제목으로 짝지음)

지원 형식: `mp3 flac m4a aac ogg opus wav webm` (재생 가능 여부는 브라우저에 따라 다를 수 있음)

## 실행

### 가장 쉬운 방법 (더블클릭)

1. [Node.js](https://nodejs.org) LTS 버전(22 이상)을 설치합니다.
2. 이 저장소를 내려받아 `music-player` 폴더를 엽니다.
3. 실행합니다.
   - **윈도우**: `시작하기.bat`을 더블클릭
   - **맥·리눅스**: 터미널에서 `./start.sh`
4. 처음 한 번은 필요한 파일을 자동으로 설치하고, 서버가 켜지면 브라우저가 `http://localhost:3000`으로 열립니다. 처음 접속하면 계정을 만드는 화면이 나옵니다.

Node.js 버전이 낮으면 무엇을 설치해야 하는지 알려 주고 멈춥니다. 서버 창에는 같은 와이파이의 휴대폰에서 접속할 주소도 나옵니다. 끄려면 그 창에서 Ctrl+C를 누릅니다.

### Docker

```bash
cd music-player
docker compose up -d --build
```

브라우저에서 `http://localhost:3000`에 접속해 계정을 만드세요.
음원과 DB는 `./data` 폴더에 저장되며, 컨테이너는 uid 1000(node) 사용자로 실행됩니다.
`./data`에 쓰기 권한 오류가 나면 `sudo chown -R 1000:1000 data`를 실행하세요.

### Node.js로 직접 실행

Node.js 22.13 이상이 필요합니다 (내장 `node:sqlite` 사용).

```bash
cd music-player
npm install
npm start          # http://localhost:3000
npm test           # API 테스트
```

## 비밀번호를 잊었을 때

서버를 켜 둔 컴퓨터에서 `music-player` 폴더를 열고 다음을 실행한 뒤, 새 비밀번호를 두 번 입력합니다. 입력한 내용은 화면에 보이지 않습니다.

```bash
npm run reset-password
```

Docker로 실행 중이면 `docker compose exec music npm run reset-password`를 씁니다. 바꾸고 나면 모든 기기의 로그인이 끊기니 새 비밀번호로 다시 로그인하세요. 서버를 켜 둔 상태에서 실행해도 됩니다.

## 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` | 음원, 커버, DB(`library.db`) 저장 위치 |
| `MAX_UPLOAD_MB` | `200` | 파일 하나의 최대 크기 |
| `AUTO_BACKUP_KEEP` | `7` | 자동 백업 보관 일수. 서버가 하루 한 번 `DATA_DIR/backups/`에 백업 파일을 저장합니다 (`0`이면 끔) |
| `COOKIE_SECURE` | `false` | HTTPS로만 접속할 때 `true` |
| `TRUST_PROXY` | `false` | 리버스 프록시 뒤에서 실제 접속 IP를 쓰려면 `true` |

## 휴대폰 홈 화면에 앱처럼 추가하기

서버 창에 나오는 "같은 와이파이" 주소(예: `http://192.168.0.12:3000`)를 휴대폰 브라우저로 연 뒤:

- **아이폰(사파리)**: 공유 버튼 → "홈 화면에 추가". 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열립니다.
- **안드로이드(크롬)**: 메뉴 → "홈 화면에 추가". 집 와이파이 주소(http)로는 바로가기로만 추가되고, 앱처럼 설치하려면 HTTPS 주소(아래 "외부에서 접속하려면")가 필요합니다.

## 외부에서 접속하려면

집 밖에서 접속할 때는 HTTPS를 꼭 쓰세요. 비밀번호가 평문으로 오가면 안 됩니다.
가장 간단한 방법은 [Caddy](https://caddyserver.com/)를 앞에 두는 것입니다.

```
music.example.com {
    reverse_proxy localhost:3000
}
```

이렇게 둘 때는 `COOKIE_SECURE=true`, `TRUST_PROXY=true`를 켜 주세요.
집 회선이라면 공유기 포트포워딩 대신 Tailscale이나 Cloudflare Tunnel을 쓰는 게 더 안전합니다.

## 구조

```
music-player/
├── server/
│   ├── index.js       # 앱 구성, 설정, 에러 처리
│   ├── db.js          # SQLite 스키마
│   ├── auth.js        # 계정, 세션 쿠키, 로그인 제한
│   ├── tracks.js      # 업로드, 메타데이터, 스트리밍, 커버
│   └── playlists.js   # 플레이리스트 CRUD, 순서 변경
├── public/            # 프론트엔드 (빌드 없는 바닐라 JS)
│   ├── index.html
│   ├── style.css
│   └── app.js
└── test/api.test.js
```

## API 요약

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/auth/status` | 로그인 상태, 최초 설정 필요 여부 |
| POST | `/api/auth/setup` · `/login` · `/logout` | 계정 만들기, 로그인, 로그아웃 |
| POST | `/api/auth/password` | 비밀번호 바꾸기 `{ currentPassword, newPassword }` |
| GET / POST | `/api/tracks` | 곡 목록 / 업로드 (`multipart`, 필드명 `files`) |
| PATCH | `/api/tracks/:id` | 곡 정보 수정 `{ title, artist, album }` (보낸 것만 바뀜) |
| POST | `/api/tracks/:id/plays` | 한 번 들었음을 기록 (들은 횟수 +1) |
| GET / PUT | `/api/tracks/:id/lyrics` | 가사 조회 / 저장 `{ lyrics }` (비우면 삭제) |
| DELETE | `/api/tracks/:id` | 곡 삭제 (파일 포함) |
| POST | `/api/tracks/bulk-delete` | 여러 곡 한꺼번에 삭제 `{ trackIds: [] }` → `{ deleted, missing }` |
| GET | `/api/tracks/:id/stream` · `/cover` | 오디오 스트림 (Range 지원), 커버 이미지 |
| GET / POST | `/api/playlists` | 플레이리스트 목록 / 만들기 |
| GET / PATCH / DELETE | `/api/playlists/:id` | 상세(곡 포함), 이름 변경, 삭제 |
| POST | `/api/playlists/:id/tracks` | 곡 추가 `{ trackIds: [] }` |
| DELETE | `/api/playlists/:id/tracks/:entryId` | 곡 빼기 |
| GET | `/api/backup` | 라이브러리 백업 JSON 내려받기 |
| POST | `/api/backup/restore` | 백업 복원 (지금 있는 곡에만 적용) |
| GET | `/api/backup/auto` | 서버의 자동 백업 목록 |
| POST | `/api/backup/auto/:name/restore` | 자동 백업 하나로 복원 |
| GET | `/api/playlists/:id/export.m3u8` | 플레이리스트를 .m3u8로 내려받기 |
| PUT | `/api/playlists/:id/order` | 순서 변경 `{ entryIds: [] }` |
