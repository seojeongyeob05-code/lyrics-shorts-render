# 다시, 5시 20분 — 기획 문서

> 영어로만 돌아가는 작은 동네에서, 같은 오후를 되풀이하며 진짜 영어를 익히는 게임.

## 한 줄 정의

목표만 한국어로 주어지고, 간판·대사·안내문은 모두 영어인 2D 동네에서 정해진 시간 안에 목표를 이루는 게임이다. 실패하면 **주마등(오답노트)**으로 내 선택이 무슨 의미였는지 되짚고, 배치가 조금 바뀐 **같은 오후 5시 20분**으로 돌아간다.

## 핵심 정신

1. **지식이 곧 진행이다.** 해금 시스템은 없다. `SECURITY OFFICE`라는 글자를 읽을 수 있으면 길이 열리고, 못 읽으면 헤맨다. 자물쇠는 플레이어 머릿속에만 있다.
2. **통하면 장땡.** 문법이 엉망이어도 뜻이 통하면 NPC는 알아듣는다. 대신 NPC가 자연스러운 표현으로 되받아주고(리캐스트), 판이 끝나면 더 자연스러운 문장을 보여준다.
3. **실패는 벌이 아니라 보상이다.** 망한 판의 주마등이 학습의 본체다. 실수를 `무관` / `정반대` / `거의 맞음` / `한국어`로 나눠 설명한다.
4. **외워서 깨지 못하게.** 회귀할 때마다 방 배치와 지갑의 생김새가 바뀐다. 순서를 외운 사람은 막히고, 단어를 아는 사람은 뚫는다.

## 소통 수단 세 층

| 수단 | 장점 | 비용 |
|---|---|---|
| 영어로 말하기 | 빠르고 확실함 | 1분 |
| 몸짓 (가리키기, 시늉, 갸웃) | 몰라도 시도 가능. NPC가 그 몸짓을 영어로 바꿔 말해줌 | 1분 30초 |
| 번역기 | NPC의 마지막 말을 한국어로 확인 | 2분 30초 |

- 한국어로 말하면 NPC는 못 알아듣는다. 막는 게 아니라 안 통할 뿐이다.
- 😕 갸웃하기(되묻기)를 하면 NPC가 더 쉽게, 몸짓을 섞어 다시 말해준다.

## 시간

턴 대신 **세계 안의 시계**를 쓴다. 오후 5시 20분에 시작하고 경비실은 6시에 닫는다. 걷기, 말하기, 몸짓, 번역기가 모두 시간을 쓴다. 시간이 흐를수록 화면이 해 질 녘처럼 어두워진다.

## 난이도

- **NPC 성격이 곧 난이도다.** 할머니는 언제나 천천히 쉬운 영어로 말하는 안전지대이자 살아 있는 사전이다. 경비원은 업무적이고, 카페 직원은 바쁘고 빠르다.
- 구역마다 사는 사람이 다르니 구역 난이도도 다르다. (프로토타입은 건물 1층 하나)

## 성장 표시

- **단어 도감**: 본 단어(👀), 뜻을 알게 된 단어(💡), 실제로 써서 통한 단어(✋)를 기록한다. 무언가를 막지는 않고 보여주기만 한다.
- 이후: NPC가 나를 기억하고 반응이 바뀌는 것으로 성장을 보여준다.

## 첫 상황: 잃어버린 지갑

> 길을 걷다 지갑이 없다는 걸 깨달았다. 방금 전까지 있던 건물로 돌아왔지만, 누군가 분실물로 알고 경비실에 맡긴 것 같다.
> **목표: 경비실로 가서 지갑을 무사히 되찾기**

1. **읽기**: 로비에서 `SECURITY OFFICE` 간판을 찾는다. 모르면 청소부에게 묻고 방향(left / right / straight ahead)을 알아듣는다.
2. **듣기**: 경비원의 "What does it look like? What color is it?"를 알아듣는다.
3. **말하기**: 지갑의 색깔과 안에 든 것(학생증, 가족사진, 콘서트 표)을 영어로, 또는 가리키기·시늉으로 증명한다.

## 프로토타입 범위 (1일차)

- 웹 단일 파일(`index.html`), 서버나 LLM 없음. 대사는 키워드 판정.
- 건물 1층 맵, 방 5개(경비실·카페·화장실·우편물실·헬스장), NPC 4명(경비원·청소부·할머니·카페 직원).
- 시계, 몸짓, 번역기, 주마등, 회귀(배치 셔플), 단어 도감(브라우저 저장).

## 앞으로

- LLM을 게임 마스터로 써서 자유 입력 판정과 상황 생성
- 같은 동네에서 이어지는 여러 상황(택배, 카페 주문, 할머니 심부름)
- NPC 일과표(시간대별로 다른 곳에 있음)
- 음성 입력
